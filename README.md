# FocusFlow

A simple task planner with a Pomodoro focus timer, built with HTML, CSS and JavaScript for IDCC 2026.

## Features
- Add, complete and delete tasks
- Filter tasks (All / Active / Done)
- 25-minute focus timer
- Dark mode
- Data saved in the browser (localStorage)
- Responsive design

## Run
Open `index.html` in any browser, or visit the live site:
